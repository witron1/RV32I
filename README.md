# RV32I Processor Core

A self-made RISC-V processor implementation based on the RV32I instruction set architecture.

This project is a personal learning effort and a work in progress. It was developed in VS Code using Icarus Verilog for simulation and debugging. The design is not yet fully complete and has not been thoroughly tested in hardware or under extensive verification.

## Overview

- Implements the RV32I base integer instruction set
- Built as an educational RISC-V processor project
- Developed with Verilog and simulated using `iverilog`
- Intended for learning, experimentation, and further development

## Current Status

This repository is still under active development. The core functionality is being refined, and validation is ongoing.

## Tools Used

- VS Code
- Icarus Verilog (`iverilog`)

## Notes

This project is an unfinished prototype and should be treated as experimental. It is intended for learning and exploration rather than production use.
